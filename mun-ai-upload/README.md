# 🤖 MUN AI — Локальный ИИ-ассистент с RAG-поиском

MUN — это локальный ИИ-ассистент, работающий на базе 7B-модели (LoRA) с системой RAG (Retrieval-Augmented Generation) для точного поиска по законам РФ.

## 🛠 Технологии
*   **Backend:** Python, FastAPI, PyTorch, Transformers, PEFT (LoRA)
*   **RAG:** FAISS, Sentence-Transformers (multilingual-e5-large)
*   **Frontend:** HTML, CSS, Vanilla JS
*   **База данных:** SQLite

## ✨ Основные фичи
*   **Юридический режим:** Поиск по 7500+ статьям (ТК, ГК, КоАП) и объяснение их простым языком.
*   **Защита от галлюцинаций:** Модель опирается только на найденные статьи, не выдумывая законы.
*   **Живое общение:** Эмпатия, поддержка и структурированный план действий.
*   **Удобный UI:** Сохранение истории чатов, кастомная анимация, регистрация.

## 🚀 Как запустить (локально)
1. Установите зависимости: `pip install -r requirements.txt`
2. Скачайте базовую модель (Qwen/Mistral) и положите в папку `lora_mun`.
3. Запустите сервер: `python server_lora.py`
4. Откройте `chat.html` в браузере.

*Примечание: Веса модели не включены в репозиторий из-за размера.*
